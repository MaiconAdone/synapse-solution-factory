# SYNAPSE Market Radar

Este diretorio guarda leituras periodicas de sinais externos para evoluir o SYNAPSE.

Fontes iniciais:

- Hacker News Show: projetos tecnicos emergentes.
- Product Hunt: sinais de produto, UX, automacao, agents e infraestrutura.

O radar classifica sinais em:

- cost_optimization
- agents
- rag_mcp
- observability
- web_automation
- ux_product
- ml_data

Use a task `SYNAPSE: Market Radar + Context Filter` para gerar um relatorio em
`docs/radar/YYYY-MM-DD.md` e um JSON em `output/market_radar/YYYY-MM-DD.json`.
