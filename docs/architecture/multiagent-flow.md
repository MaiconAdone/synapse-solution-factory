# Multi-Agent Flow

1. The orchestration manager receives a task.
2. The task is routed to specialized agents by domain.
3. Agents write decisions and reusable patterns to persistent memory.
4. Workflows enforce quality gates before release.
5. Testing/QA and documentation agents close the loop.

Default topology: hierarchical-mesh.

Default coordination: distributed.

Default consensus mechanism: majority, matching the Ruflo runtime.
