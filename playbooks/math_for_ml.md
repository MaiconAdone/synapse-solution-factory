# Mathematics for Machine Learning Playbook

## Practical Foundations

- Learning problem framing: experience, task, and performance measure.
- Hypothesis spaces: model family, inductive bias, capacity, and variance risk.
- Linear algebra: vectors, matrices, projections, distances, similarity.
- Probability: uncertainty, conditional probability, calibration.
- Optimization: loss functions, gradients, convergence, regularization.
- Statistics: sampling, confidence intervals, hypothesis checks.

## Engineering Use

- Choose metrics that match the business objective.
- Compare simple baselines against the selected hypothesis family before adding complexity.
- Inspect class imbalance before trusting aggregate scores.
- Use confidence intervals for evaluation deltas.
- Document feature transformations and leakage checks as part of the model evidence.
- Validate embedding similarity with domain-specific examples.
